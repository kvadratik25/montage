# Монтаж PROАВТО

Готовый статический сайт с синхронизацией через Supabase.

## Публикация на GitHub Pages

1. Загрузите `index.html` и `supabase-sync.js` в корень репозитория.
2. Откройте **Settings → Pages**.
3. В **Build and deployment** выберите **Deploy from a branch**, ветку `main`, папку `/root` и нажмите **Save**.
4. Откройте выданную GitHub Pages ссылку.

## Вход

- Владелец вводит свою настоящую почту и пароль Supabase.
- Заказчик вводит логин `proavto` и созданный для него пароль. Технический адрес `@montage.local` сайт подставляет сам.
- Заказчик видит только неоплаченные ролики и общую сумму. Добавление, редактирование, удаление, тарифы и аналитика ему недоступны.

При первом входе владельца, если облачная таблица пуста, сайт перенесёт в Supabase встроенную историю роликов. После этого изменения синхронизируются между устройствами.

Файл `supabase.sql` нужен только для повторной настройки нового проекта. В текущем проекте этот SQL уже выполнен.

## Кнопка «Я оплатил»

Перед загрузкой новой версии сайта один раз откройте **Supabase → SQL Editor**, вставьте содержимое файла `payment-workflow.sql` и нажмите **Run**. После этого заказчик сможет отмечать оплату каждого ролика, а владелец — подтверждать её или возвращать статус «Не оплачено».
