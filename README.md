# Монтаж — учёт роликов

Одностраничный HTML-инструмент для учёта монтажа роликов.

## Публикация на GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите в корень репозитория файлы `index.html` и `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main`, папку `/ (root)` и нажмите **Save**.

После публикации GitHub покажет адрес сайта.

## Важно о данных

Сейчас записи сохраняются в `localStorage` браузера. Поэтому данные на телефоне и компьютере будут независимыми.

Для общей синхронизации потребуется облачный API и база данных. При подключении Yandex Cloud можно использовать:

- Object Storage — размещение сайта;
- API Gateway — HTTPS API;
- Cloud Functions — добавление, редактирование и удаление записей;
- YDB — общая база роликов.

Закрытый раздел «Что если» открывается паролем `123456`. Это клиентская защита интерфейса, а не полноценная серверная авторизация.
